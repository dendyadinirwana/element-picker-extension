# Element Picker Chrome Extension

Modern Chrome Extension (Manifest V3) with native **Side Panel**, live computed style inspection, smart breadcrumb hierarchy, code export (HTML, JSX, CSS, Selector, Text, Standalone ZIP), **Area Snip (Box Cropper)**, and **Instant OTA Updates via GitHub Releases**.

## 🚀 Key Capabilities

- **Side Panel First UI (Shadcn & UI/UX Pro Max):** Clean interface with automatic Light / Dark mode support.
- **Deep Inspector Engine:** Live computed CSS metrics (dimensions, box-model, typography, colors, border radius, display, flex/grid properties).
- **Dedicated Export Section:** Instant copy as Clean HTML, React JSX, CSS Rules, CSS Selector, PNG Screenshot, Text, or full standalone ZIP bundle.
- **Area Snip (Box Cropper):** Crop canvas or any viewport region with instant copy to clipboard (`⌘/Ctrl+Shift+S`).
- **Interactive Changelog Accordion:** Multi-version release history with feature highlights.
- **GitHub OTA Updates:** Auto-detect new releases from `dendyadinirwana/element-picker-extension`, download update bundle, and reload runtime.
